# Animal companion subsystem

## Objective
Create a real animal companion creation, persistence, runtime, and upgrade subsystem that can support both ranger and druid companion feat chains honestly.

## Blocked feats
- `animal-companion`
- `animal-companion-druid`
- `mature-animal-companion-druid`
- `specialized-companion-druid`

## Required subsystem work
- Define a concrete animal companion entity/state model comparable in seriousness to the familiar flow.
- Add creation/selection UI and persistence for initial companion choice.
- Add runtime derivation for companion actions, statistics, and owner links.
- Add upgrade paths for mature and specialized companions, including specialization choice persistence.

## Verification required after implementation
- Re-run feat verification for all blocked animal companion feats.
- Confirm creation or level-up selection, persistence, runtime state, and visible gameplay effect for each feat.
- Update the feat verification plan/checklist only after end-to-end confirmation.
