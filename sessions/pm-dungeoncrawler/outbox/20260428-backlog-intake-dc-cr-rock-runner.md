"What if there was a speed-running mode where you try to get through the dungeon as fast as possible?"

## Feature Description
Rock Runner is a competitive speed-run mode for Dungeoncrawler. Players attempt to complete a dungeon as fast as possible, alone or in a race against others. The mode prioritises speed over survivability and introduces a global leaderboard for bragging rights.

## Target Users
- Competitive players who want a high-skill, repeatable challenge
- Returning players looking for replay value beyond story/campaign modes
- Players interested in community rankings and leaderboards

## Key Capabilities (draft)
1. **Speed-run timer** — starts on dungeon entry, stops on boss kill or exit reached
2. **Leaderboard** — global + per-dungeon rankings; filterable by dungeon, party size, class
3. **Rock Runner mode toggle** — separate from campaign/story mode; no story content shown
4. **Seeded dungeons** — fixed dungeon layouts for fair comparison (same seed = same map)
5. **Run replay / ghost system** — optional; record movement paths and actions for community viewing
6. **Badge / achievement system** — Rock Runner-specific milestones (first completion, sub-5min, no-damage run, etc.)
