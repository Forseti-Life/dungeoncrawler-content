## Separation: Private vs. Public

### What Stays Private (Operational Monorepo)
- Production credentials and API keys
- Database backups and exports
- Operational session data
- Site-specific configuration
- Internal analytics

### What Goes Public (GitHub)
- Source code (clean, production-ready)
- Documentation (setup, API, architecture)
- Configuration templates (.env.example)
- Community examples and guides
- Contributing guidelines

### Integration Model
1. Changes made in public repos
2. Pull requests reviewed in public
3. Merged into public repo
4. Integrated back to private monorepo for deployment
