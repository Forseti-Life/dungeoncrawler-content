# Security Policy

## Reporting Issues

Email security concerns (do not open public issues): security@example.com

## Security Practices

- All inputs validated via Drupal Forms API
- File uploads restricted to safe formats
- Database queries use prepared statements
- Sensitive data stored in environment variables
- CSRF tokens required for all state-changing operations

## Known Vulnerabilities

None. See: https://www.drupal.org/project/job_application_automation/issues
